# Drafts for fractum.faith

Source drafts for review. Nothing here is wired into the Publii site; each file is Markdown you can paste into a new Publii post or page (switch the editor to Markdown, or paste into the WYSIWYG editor and fix headings).

Each file begins with a header block: title, type, suggested placement in the site, an excerpt for the post list, suggested tags, and status. Delete the header block when pasting; Publii has its own fields for those.

Numbers in parentheses are body word counts.
